# Flicksy final identity

The final mark is based on **Media Grid — Option C**, tightened with the compact variant's spacing.

## Meaning

- Four rounded tiles reflect Flicksy's adaptive media grid.
- The negative space reads as an abstract **F**.
- The right tiles advance upward, suggesting a quick flick through media.
- The construction remains legible at macOS icon and toolbar sizes.

## Assets

- `flicksy-mark.svg` — flexible `currentColor` master.
- `flicksy-mark-black.svg` and `flicksy-mark-white.svg` — explicit production variants.
- `flicksy-app-icon.svg` — editable 1024 × 1024 macOS icon artwork.
- `Exports/` — transparent mark PNGs, the 1024 px app icon, and compiled macOS `.icns`.
- `showcase.html` — final identity presentation and download page.

The complete 16–1024 px AppIcon set is installed in `flicksy-app/Flicksy/Assets.xcassets/AppIcon.appiconset`.
