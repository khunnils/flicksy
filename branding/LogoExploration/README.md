# Flicksy logo exploration

Eight monochrome logo directions for Flicksy, a fast, minimal native macOS media browser.

The marks are intentionally color-independent and use `currentColor`. This keeps the first decision focused on silhouette, proportion, and meaning before app-icon materials or color are introduced.

1. **Flick Stack** — offset media cards communicate rapid browsing; the top card carries an abstract F.
2. **Focus Frame** — an open preview frame makes Quick Look-like immediacy the central idea.
3. **Skim Loop** — a continuous path suggests fluid scrubbing across mixed media.
4. **Media Grid** — a thumbnail grid quietly resolves into an F; closest to Flicksy's main interface.
5. **Signal F** — an F gains two waveform bars, bridging visual and audio media.
6. **Scrub Window** — a scrubber cutting through a native window emphasizes speed.
7. **Flick Corner** — a lifting media-tile corner gives the name “Flicksy” a literal gesture.
8. **Quiet Aperture** — a compact, iconic aperture with a rounded F cutout.

Open `index.html` to compare the marks in light/dark modes and at 16, 32, 64, and 128 px.

The selected **Media Grid** direction has three focused variants in `MediaGridRefinement/index.html`.
