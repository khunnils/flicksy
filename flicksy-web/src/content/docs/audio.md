Audio sits in the same library as images and video. Switch to the **Audio** tab (**⌘3**) for a waveform-first list, or stay on **All** (**⌘1**) to see every media type together.

## See the sound

Each audio file shows a waveform. Click in the waveform to play from that point. You do not need to guess from filenames or open a separate app to find a hit.

When an audio file is selected, the inspector provides transport controls:

| Action | Shortcut |
| --- | --- |
| Play / Pause | Space |
| Rewind 5 seconds | ← |
| Forward 5 seconds | → |
| Jump to start | ⌘← |
| Jump to end | ⌘→ |

In the library grid, **Return** also plays or pauses the current audio selection.

## Loop a range

Drag the play-range handles on the waveform, then turn looping on. Playback stays inside that selection so you can audition a cut without riding the playhead.

## Trim in place

Trim keeps the selected range and **overwrites the original file**. Duplicate the clip first if you still need the untrimmed version.

## Edit meta tags

Choose **Edit Meta Tags…** from the File menu, context menu, or command palette. This edits the tags stored in the audio file itself.

Library tags and collections are separate — they live in Flicksy and do not rewrite the file. See [Organize](/docs/organize).
