Organization in Flicksy is a layer on top of your folders. Favorites, tags, and collections point at the original files. Nothing is copied into a new library.

## Favorites

Select one or more items and favorite them from the organize popover (**⌘T**), the command palette, or the context menu. Open **Favorites** in the sidebar whenever you want that set back.

## Tags

Tags travel across folders. Label a clip in one project folder and a still from another, then click the tag in the sidebar to see every match in one view.

Create, rename, and delete tags from the sidebar, **⌘T**, or **⌘K**. Applying a tag to a selection does not move the files.

## Collections

Collections are working sets — an episode, a launch, a pile of best openers — assembled from anywhere you browse. Originals stay in their folders.

Add the current selection to a collection from **⌘T** or the command palette. Open a collection from the sidebar or **⌘J**.

## Organize popover

**⌘T** opens organization for the current selection: favorite, tags, and collections in one place.

## Clipboard history

Flicksy keeps recent **copied images** in a Clipboard source in the sidebar. Browse, reuse, and paste them like other media. This history is stored by Flicksy; clearing it does not empty the system pasteboard.

File copy and paste (**⌘C** / **⌘V**) still use the Mac pasteboard and operate on the original files. See [Browsing](/docs/browsing).
