Flicksy is a window onto local media. It does not create a library database you have to maintain, and it does not copy files into an app-specific store.

## Add and remove folders

Use **Add Folder…** in the sidebar, the command palette, or drag a folder from Finder onto Flicksy. External drives work the same way as folders on the internal disk.

To stop browsing a location, hide it from the sidebar. Hiding a folder does not delete anything on disk.

## Library tabs

The toolbar tabs filter what you see in the current source:

| Tab | Shortcut | Shows |
| --- | --- | --- |
| All | ⌘1 | Images, video, and audio together |
| Images & Video | ⌘2 | Visual media in a thumbnail grid |
| Audio | ⌘3 | Audio as a list with waveforms |

Clipboard history is image-only, so the Audio tab is unavailable there.

## Jump to anything

Press **⌘J** and type the name of a folder, tag, collection, Favorites, or Clipboard. Return opens that source. This is the fastest way to move around a large library.

## Command palette

Press **⌘K** to search files by name or run a command. From the palette you can open a clip, compare images, favorite or tag a selection, rename, reveal in Finder, and more. Keep typing to narrow the list.

## Search, sort, and thumbnail size

- **⌘F** finds media by name in the current source.
- Use the sort control to order by name, date, size, or other metadata.
- On Images & Video, **+** and **−** change thumbnail size. The same keys zoom an image in the preview.

## Work with files

Flicksy uses familiar Mac file actions. They operate on the original files.

- **⌘C** copies the selected files.
- **⌘V** pastes into the current folder when that folder is writable.
- **⌘⌥C** copies the file path.
- **⌘⌥R** reveals the selection in Finder.
- **⌘⌫** or **Delete** moves files to Trash.
- Drag thumbnails into Final Cut, Premiere, CapCut, or any app that accepts files.

Get Info (**⌘I**) shows dimensions, duration, dates, file size, bit rate, sample rate, and channels.

Rename and duplicate are available from the context menu and the command palette. Image resize lives in the command palette when an image is selected.
