# Media Grid refinement

Three targeted refinements of the selected Media Grid direction:

- **A — Balanced**: the most neutral and timeless construction, with optically tuned tile proportions.
- **B — Compact**: tighter spacing and more visual mass for maximum clarity at 16–32 px.
- **C — Flick**: the right tiles advance upward, adding motion and a more ownable Flicksy gesture.

All marks use a `0 0 100 100` viewBox and `currentColor`.
